# Bingo Frontend 🎲

¡Bienvenido al proyecto **Bingo Frontend**! Este es un juego de Bingo interactivo desarrollado con tecnologías modernas de frontend. Es ideal para jugar entre amigos o usarlo como base para un proyecto más grande.

## 🚀 Características

- Generación automática de cartones de Bingo.
- Marcado de números en tiempo real.
- Notificaciones al completar una línea o Bingo.
- Diseño responsive para usar en dispositivos móviles y de escritorio.
- Conexión con una API para resultados en tiempo real.

## 🛠️ Tecnologías utilizadas

- **HTML5**: Estructura de la aplicación.
- **CSS3**: Estilos y diseño responsivo.
- **JavaScript**: Lógica del juego.
- **Framework/Librería Backend: Spring Boot.
